# Лабораторная работа 15 - Работа с сетью

Flutter приложение для просмотра информации о команде SpaceX с использованием API.

## Функциональность

- ✅ Просмотр списка команды SpaceX с API
- ✅ Экран с подробной информацией о члене команды
- ✅ Индикатор прогресса во время загрузки
- ✅ Обработка ошибок сети с кнопкой повтора
- ✅ Кеширование данных локально с использованием Hive
- ✅ Сохранение избранных элементов
- ✅ Офлайн режим с возможностью просмотра кешированных данных
- ✅ Архитектура на основе Cubit (flutter_bloc)

## Установка и запуск

1. Установите зависимости:
```bash
flutter pub get
```

2. Сгенерируйте код для JSON сериализации:
```bash
flutter pub run build_runner build --delete-conflicting-outputs
```

3. Запустите приложение:
```bash
flutter run
```

## Структура проекта

- `lib/models/` - Модели данных (CrewMember)
- `lib/services/` - Сервисы для работы с API и кешированием
- `lib/bloc/` - Управление состоянием (Cubit/Bloc)
- `lib/screens/` - UI экраны приложения

## Используемые технологии

- **http** - для HTTP запросов
- **flutter_bloc** - для управления состоянием
- **hive** - для локального кеширования
- **connectivity_plus** - для проверки подключения к интернету
- **url_launcher** - для открытия ссылок в браузере

## API

Используется SpaceX API: https://api.spacexdata.com/v4/crew
