# Итоговая реализация лабораторной работы №11-12

## Реализованный функционал

### 1. ✅ Firestore интеграция
- Все сущности (Hotels, Favorites, Users) хранятся в Firebase Firestore
- Сохранена архитектура BLoC
- Реализованы CRUD операции для всех сущностей
- Поддержка офлайн-режима с автоматической синхронизацией

### 2. ✅ Аутентификация
- Регистрация через Email/Password
- Вход через Email/Password
- Вход через Google (дополнительный провайдер)
- Сброс пароля с отправкой ссылки на email
- Автоматическая проверка статуса аутентификации

### 3. ✅ Страница информации о пользователе
- Отображение имени, email, роли, ID пользователя
- Отображение статуса (online/offline)
- Отображение времени последней активности
- Кнопка выхода из аккаунта

### 4. ✅ Realtime Database
- Хранение статуса пользователя (online/offline)
- Хранение времени последней активности
- Автоматическое обновление статуса при входе/выходе
- Периодическое обновление времени активности

### 5. ✅ Firebase Messaging
- Инициализация сервиса уведомлений
- Обработка уведомлений в foreground режиме
- Отображение локальных уведомлений
- Обработка фоновых сообщений

### 6. ✅ Firebase Remote Config
- Управление кнопкой like (включение/выключение)
- Изменение цвета блока через Remote Config
- Автоматическая загрузка конфигурации при запуске

### 7. ✅ Firebase Analytics
Реализованы следующие события:
1. `app_open` - открытие приложения
2. `login` - вход пользователя (email/google)
3. `signup` - регистрация пользователя (email/google)
4. `hotel_view` - просмотр отеля
5. `favorite_toggle` - добавление/удаление из избранного
6. `screen_view` - просмотр экранов (user_info, favorites)

## Структура проекта

### Сервисы (`lib/services/`)
- `firestore_service.dart` - работа с Firestore
- `auth_service.dart` - аутентификация
- `realtime_db_service.dart` - статус пользователя
- `remote_config_service.dart` - Remote Config
- `messaging_service.dart` - уведомления
- `analytics_service.dart` - аналитика

### BLoCs (`lib/blocs/`)
- `auth/` - аутентификация
- `hotels/` - управление отелями
- `favorites/` - избранное
- `current_user/` - текущий пользователь

### Страницы (`lib/pages/`)
- `login_page.dart` - страница входа
- `register_page.dart` - страница регистрации
- `reset_password_page.dart` - сброс пароля
- `user_info_page.dart` - информация о пользователе

## Настройка Firebase

Перед запуском приложения необходимо:

1. Установить FlutterFire CLI и настроить проект:
```bash
dart pub global activate flutterfire_cli
flutterfire configure
```

2. Настроить все сервисы в Firebase Console (см. FIREBASE_SETUP.md)

3. Установить зависимости:
```bash
flutter pub get
```

## Демонстрация функционала

### Офлайн-режим
1. Откройте приложение с интернетом
2. Загрузите данные (отели, избранное)
3. Отключите интернет
4. Продолжайте работать с данными (они кэшируются)
5. Включите интернет - данные автоматически синхронизируются

### Remote Config
1. В Firebase Console измените `like_button_enabled` на `false`
2. Перезапустите приложение - кнопка like исчезнет
3. Измените `block_color` на другой цвет (например, `#FF5733`)
4. Перезапустите приложение - цвет кнопки "Book Now" изменится

### Messaging
1. Отправьте тестовое сообщение через Firebase Console
2. Уведомление отобразится на устройстве

### Analytics
1. Откройте Firebase Console > Analytics
2. Просмотрите события в реальном времени или в отчетах

## Примечания

- Все данные синхронизируются автоматически при восстановлении подключения
- Статус пользователя обновляется в реальном времени
- Приложение поддерживает работу в офлайн-режиме благодаря Firestore persistence
